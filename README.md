# 大地藝術祭 2026 作品地圖

越後妻有大地藝術祭 2026 常設與公開作品的互動地圖：<https://map.echigo.fans/>（由 [越後飯 ECHIGO FAN](https://echigo.fans/) 製作）

- 依日期查看各作品開館或休館（休館日依官方 2026 營業日曆）
- 收藏「我的清單」，資料只存在自己的瀏覽器
- 排出開車、步行或巴士路線，可開啟 Google 地圖導航
- 單一頁面 `index.html`，手機與桌機皆可使用

作品位置參考官方 2024 作品地圖，開放資訊以官方公告為準。底圖 © OpenStreetMap 貢獻者，區域界線：國土數值情報 N03。
